# Portfolio

Two versions of my personal portfolio site, before [skvkpandey.com](https://skvkpandey.com).

| Folder | Built | What it is |
|---|---|---|
| `v1/` | 2022 to 2024 | One-page portfolio on a Bootstrap template, with a PHP contact form |
| `v2/` | 2024 to 2025 | Hand-built site with separate Experience and Projects pages; projects and skills load from JSON |

Plain HTML, CSS and JavaScript. Open `index.html` in either folder, or serve it with `python -m http.server`.

The current site lives in its own repository, [skvkpandey.com](https://github.com/SKVKPandey/skvkpandey.com).
